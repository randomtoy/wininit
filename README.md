# wininit

`wininit` is an independent, open-source Windows initialization agent written in Go. It targets Windows Server guests on QEMU/KVM and OpenStack and is designed to grow support for NoCloud and ConfigDrive metadata without copying Cloudbase-Init's implementation.

The repository is in its foundation phase. No VM provisioning capability is claimed yet.

See the project documentation added alongside the first functional implementation for supported commands, build and installation instructions, architecture, and limitations.
